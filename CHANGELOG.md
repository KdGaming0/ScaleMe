# Sacle Me 3.3.0

- feat: added support for Minecraft 26.2
- feat: rebuilt the settings menu to be much easier to understand
  - the "master" switches are gone — every setting now works on its own, so there is no
    hidden toggle to remember before your changes take effect
  - settings that depend on another one now stay hidden until you turn that one on, instead
    of quietly doing nothing
  - clearer names and plain-English descriptions throughout, with the normal Minecraft value
    listed on every slider so you can always get back to the default look
  - "Dropped Items" moved into the new "Sizes" tab, which now holds every size option in one
    place — 1.0 always means off
  - your existing settings carry over; only the three removed master switches are cleared
